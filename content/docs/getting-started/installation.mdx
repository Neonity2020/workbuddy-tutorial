## 下载

官方下载入口只有一个：**[www.workbuddy.cn](https://www.workbuddy.cn)**。首页点击「下载」会自动识别你的系统。桌面端支持 macOS、Windows，以及国产系统的 Linux 版本（麒麟、统信 UOS 有单独安装说明）。

<Callout type="warn" title="别从第三方站点下载">
WorkBuddy 需要读写本地文件和执行命令，装到来路不明的安装包风险很高。历史版本可以在官网的下载记录页找到，不需要去网盘找。
</Callout>

## 安装

<Tabs items={['macOS', 'Windows', 'Linux']}>
  <Tab value="macOS">
    1. 打开下载的 `.dmg`，把 WorkBuddy 拖进「应用程序」。
    2. 首次启动如果提示「无法验证开发者」，到**系统设置 → 隐私与安全性**，在底部点击「仍要打开」。
    3. 按提示授予**完全磁盘访问权限**，否则部分目录读写会失败。
    4. 可选：授予**辅助功能**（快捷键唤起）与**自动化**（操作日历、提醒事项、备忘录）。
  </Tab>
  <Tab value="Windows">
    1. 运行下载的安装包，按向导完成安装。
    2. 首次启动时允许它在防火墙提示中访问网络，否则模型调用会失败。
    3. 建议把安装目录放在非系统盘之外，产物默认写入你选择的工作空间，不占安装盘。
  </Tab>
  <Tab value="Linux">
    按发行版选择 `.deb` 或 `.rpm` 包，用包管理器安装后从应用菜单启动。麒麟与 UOS 需要额外确认系统自带的运行时依赖，官网有分系统的图文说明。
  </Tab>
</Tabs>

## 登录

启动后使用腾讯账号体系登录。登录态决定三件事：

- **积分配额**：模型调用按积分计费，余额不足会中断任务。
- **技能与专家的开关状态**：这些配置跟着账号走，换设备会自动同步。
- **定时任务的归属**：任务以当前登录身份触发，退出登录后本地定时任务不会执行。

## 首次启动会遇到的三个弹窗

<Steps>
  <Step title="工作区信任">
    打开一个含 `.codebuddy`、`.workbuddy` 等开发配置目录的项目时，会问你要不要信任。选**正常打开**加入白名单；不确定就选**受限模式**，此时不会自动加载该目录里的配置、命令和脚本。
  </Step>
  <Step title="权限模式确认">
    输入框底部默认是**默认权限**。除非你在隔离目录里反复跑可信脚本，否则不要开「允许完全访问」。
  </Step>
  <Step title="系统权限">
    macOS 会请求磁盘访问、辅助功能、自动化等授权。按需授予，不用的可以在**系统设置 → 隐私与安全性**里收回。
  </Step>
</Steps>

## 建议先做的三件设置

打开**设置**，花两分钟调这三项，后面会省很多事：

| 设置项 | 位置 | 建议 |
| --- | --- | --- |
| 自动备份 | 安全中心 → 沙箱安全 | 保持开启。改文件前自动生成快照，改错了能回退 |
| 产物通知 | 通用 → 定时任务产物通知 | 开启。长任务跑完会弹系统通知 |
| 默认工作空间 | 通用 | 指到一个专用目录，别指到桌面或下载目录根节点 |

## 卸载

正常卸载客户端即可。注意两点：

- 你的产物文件不会被删除，它们在你选择的工作空间里。
- 账号注销在客户端内发起，注销后云端会话、资料库内容会一并处理，操作不可撤销，先备份需要的东西。
