WorkBuddy 的主窗口是固定的四区布局。花三分钟认清它们，后面找东西就不用翻。

```text
┌──────────────────────────────────────────────────────┐
│  工具栏：关于 / 编辑 / 窗口                            │
├──────────┬────────────────────────┬───────────────────┤
│          │  任务标题 + 顶部操作     │                   │
│  侧边栏   │────────────────────────│     结果区         │
│  任务列表 │  对话区（消息流）        │  概览 / 产物       │
│          │────────────────────────│                   │
│  头像     │  输入框（模式/权限/附件） │                   │
└──────────┴────────────────────────┴───────────────────┘
```

## 侧边栏：任务的家

左侧按**文件夹分组**展示任务列表，支持搜索和管理。

- 任务按工作空间归组，选择过工作空间的定时任务会挂在对应空间下。
- 顶部搜索框按任务名、对话内容检索。
- 底部是头像入口，点开是设置、账号与帮助。
- 「专家·技能·连接器」「定时任务」「资料库」等模块也从这里进入。

<Callout type="tip">
任务多起来之后，用**工作空间分组**比按时间翻列表有效得多。一个项目一个文件夹，天然就是一层目录。
</Callout>

## 对话区：干活的地方

中间是核心交互区，从上到下三段：

**任务标题栏**，左侧显示任务名（可重命名），右侧是一排操作：在 CodeBuddy 打开、对话内搜索、分享任务、显示详情面板。

**消息流**，你的提问和 WorkBuddy 的执行过程。长对话时右侧会出现竖向刻度导航，每一格对应你发过的一条提问，点击可跳转。

**输入框**，底部从左到右是工作空间选择、`@` 引用、附件上传、权限按钮，右侧是模型选择与发送。

## 结果区：验收的地方

右侧面板分两个页签：

| 页签 | 内容 |
| --- | --- |
| 概览 | 任务摘要、关键结论、本次生成的主要产物 |
| 产物 | 全部文件、对话过程中的文件变更、内置浏览器预览 |

同一份文件改了几版，这里能看到版本列表并切换对比。文档、表格、PPT、网页都可以直接预览，不用下载再打开。

## 工具栏

屏幕顶部，提供三类入口：

- **关于 WorkBuddy**：版本信息、检查更新。
- **编辑**：撤销、重做、复制粘贴等文本操作。
- **窗口**：最小化、缩放、切换独立窗口。

## 一个高频误区

<Callout type="warn" title="别在对话区找文件">
产物不会「留在对话里」。生成的文件落在工作空间目录，界面上只是给你一个查看入口。想找文件，要么去结果区，要么直接去文件夹。
</Callout>
