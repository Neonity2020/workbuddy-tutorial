技能（Skill）把脚本和工作流封装成可复用的能力。装上一个技能，WorkBuddy 就多会一件事。

## 技能市场

侧边栏 **专家·技能·连接器 → 技能**，分两块：

- **技能市场**：按推荐、SkillHub、套件分类展示，卡片上带使用量和安装量，帮你判断热度。
- **已安装**：本地已装的技能，直接在对话里调用。

## 四种获取方式

| 方式 | 操作 | 适用 |
| --- | --- | --- |
| 一键安装 | 技能卡片右上角点 `+` | 已经知道要哪个 |
| 对话安装 | 直接说「帮我找一个能把网页转成 PDF 的技能」，确认候选后安装 | 只知道要做什么 |
| 上传技能 | 添加技能 → 上传技能，拖入本地技能包 | 自己或团队写好的 |
| 创建技能 | 添加技能 → 创建技能，输入任务描述，自动生成 | 需要的能力市场没有 |

对话安装只支持市场里的技能；自己打包的走上传。

## 启用、关闭、卸载

<Callout type="warn" title="关闭 ≠ 卸载">
- **关闭**：保留文件和配置，只是不再参与新任务调用。当前会话里已加载的仍可用，新会话才完全生效。
- **卸载**：彻底删除技能及其开关记录。
</Callout>

开关状态跟**账号**走，换设备自动同步。它不会改动技能包本身的 `SKILL.md`——从 `.agents` 等目录复制安装的技能始终保持原始内容。

建议只启用当前任务需要的技能：无关技能开着，既增加干扰也提高误调用概率。

批量清理：**已安装 → 批量管理**，勾多个后一次卸载。

## 什么时候该用技能

判断标准是「**缺能力**」而不是「缺方法」：

- 要读某个格式的文件、调某个 API、操作某个软件 → 技能
- 要一套专业判断标准和输出范式 → [专家](/docs/extend/expert)
- 要访问外部系统的数据、执行外部动作 → [连接器](/docs/extend/connector)

## 安全提醒

<Callout type="danger" title="第三方技能要挑">
非官方技能可能存在恶意提示词注入、越权访问、后门程序。技能调用第三方、改本地文件、执行系统命令时，都是**以你的身份**执行。

- 优先用官方推荐技能。
- 装第三方技能前，看清权限申请、来源说明和脚本内容。
- 涉及文件删除、批量写入、系统配置变更、资金操作时，先小范围验证再放大。
- 部分技能会把你的输入发往第三方（订外卖、查股票、发 IM 消息等），注意数据外发范围。
</Callout>

## 几个值得先装的

| 类型 | 解决什么 |
| --- | --- |
| 文档套件 | Word/Excel/PPT 的生成与美化，产出质量比通用生成更稳 |
| 网页搜索 | 拿到带来源的实时信息，而不是模型记忆 |
| 浏览器操作 | 需要点页面、填表单时用 |
| 格式转换 | PDF / 图片 / 音频转文字等一次性需求 |

实际可选范围以客户端里的技能市场为准，市场在持续更新。
