任务建好后，真正的效率来自**同一段对话里的连续推进**。WorkBuddy 记得前面的上下文，所以你不必重复背景，只需要说「改哪里」。

## 三种常见的追加

| 场景 | 说法示例 |
| --- | --- |
| 补充要求 | 「再加一个饼图」「字号调大一点」 |
| 调整已有结果 | 「表格按销售额降序」「报告加一段执行摘要」 |
| 继续深入 | 「导出成 PDF」「再分析一下环比变化」 |

## 执行中也能说话

模型正在跑的时候，你可以继续发消息，不用等它结束。新消息会进入输入框上方的**队列**：

- 队列里的消息支持**编辑**、**删除**、拖动排序。
- 点发送按钮可以立即把消息交给模型引导当前方向，但**不会打断**正在进行的输出。
- 当前一轮（含工具调用）结束后，队列按顺序被依次处理。

<Callout type="tip">
长任务里发现方向错了，与其按停止再重来，不如直接往队列里塞一条修正指令，让它在下一轮就拐回来。
</Callout>

## 精确引用：让「改这里」真的只改这里

这是最容易被忽略、但最提效的功能。三种引用方式：

### 引用文本

1. 在回复里**选中要改的文本**，选区上方出现操作栏。
2. 点**添加到对话**，内容作为引用进入输入框。
3. 旁边的**批注输入框**可以写一句「这里改成口语化」——不写也行，直接在输入框里补充。
4. 悬停引用可查看被引用的完整原文。

### 引用表格

鼠标悬停在表格上，右上角出现**添加到对话**图标，点击即引用整张表。适合说「这张表加一列毛利率」。

### 引用组件

图表、可视化页面这类组件（Widget）顶部同样有**添加到对话**。引用后可以说「这张图换成折线图」。

<Callout type="note" title="可以混着用">
同一条消息里可以连续添加多个引用，文本、表格、组件都行。每条引用带删除入口，删掉后正文里的引用标识会一起取消。只发引用不写字也能发送。
</Callout>

## 回退、编辑、刷新

三个操作都能改历史，都会**同时影响产物**，所以都会弹确认框。仅本地任务可用，执行中不可用。

### 回退

悬停你发过的消息，点**回退**：对话和产物一起回到这条消息之前，之后的内容全部移除。

确认框会列出受影响的产物及处理方式：

| 标注 | 含义 |
| --- | --- |
| 回退至某版本 | 产物回到那条消息之前的版本 |
| 将被删除 | 产物是消息之后才生成的，回退后删除 |
| 历史版本已被删除 | 找不到旧版，保持当前 |
| 不回退版本 | 没有更早版本，文件留在目录里 |

回退**不会重新生成**，只是退回去。要改写这条消息，用下面的编辑。

### 编辑

点消息下方的**编辑**，改完发送，WorkBuddy 从这条消息重新处理。如果之后改动过产物，会问你：**取消 / 不回退 / 回退**。

- 不回退：基于最新版继续改。
- 回退：先退回旧版本，再基于旧版改。

### 刷新

只有**最后一条**回复有刷新按钮。点它会重新生成这条回复及其产物，同样会问是否回退产物版本。

失败时页面顶部会提示对应错误，原有内容和产物保持不变，可以直接重试。

## 顶部那一排操作

| 按钮 | 用途 |
| --- | --- |
| 在 CodeBuddy 打开 | 用 CodeBuddy 打开当前工作空间继续写代码（装了 CodeBuddy 且为代码开发模式时出现） |
| 对话内搜索 | 关键词定位历史消息 |
| 分享任务 | 生成公开链接，可发到任意渠道 |
| 显示详情面板 | 打开右侧结果区 |

## 长对话怎么不迷路

对话轮次多了，对话区右侧会出现竖向刻度导航：

- 鼠标移上去展开你发过的**全部提问**（只有你的，不含回复，过长会截断）。
- 点击任意一条即可跳转。
- 手动滚动时当前位置会同步变化。

对话太窄时它会自动隐藏（比如打开了右侧面板），收起面板或拉宽窗口就回来了。

## 看进度、接管、中断

执行过程中，对话区会显示阶段说明（「正在分析数据」「正在生成报告」）、已生成结果摘要、可展开的中间步骤。

需要连接 MCP 服务时，会显示「正在连接 MCP 服务」和已连接数/总数，可以展开看明细。全部就绪后这段进度会自动消失，不留在历史里。

想停下就点输入框区域的停止入口。中断后仍可以继续补充说明、调整需求重发，或基于已有内容往下走——**重点是接着聊，不是重新开始**。

## 保存与复制组件

图表、可视化页面右上角有三个入口：

- **添加到对话**：作为引用加入输入框。
- **下载到本地**：保存组件文件。
- **更多（⋯）**：复制为图片、保存为图片、复制代码、查看代码。

组件还在生成中时，前两项图片操作不可用，等加载完再点。
