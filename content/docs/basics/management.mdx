WorkBuddy 天生支持多任务并行。同时开三个任务不稀奇，稀奇的是三天后还能找到它们。

## 任务列表怎么组织

左侧边栏按**文件夹分组**展示任务：

- 选过工作空间的任务，归到对应目录下。
- 没选工作空间的，归到默认任务组。
- 定时任务在列表里只占**一个入口**（带定时任务图标），它的历次运行不会各自变成一条任务。

<Callout type="tip" title="用目录管理任务">
与其给任务起长名字，不如把同类任务放进同一个工作空间。目录天然是一层分组，而且和磁盘上的文件结构一致——找文件时不用二次回忆。
</Callout>

## 找任务

| 方式 | 适用 |
| --- | --- |
| 滚动列表 | 最近的任务 |
| 搜索框 | 记得关键词，按任务名或对话内容检索 |
| 按状态筛选 | 只看运行中 / 已完成 / 失败 |
| 对话内搜索 | 已经打开任务，找某段话 |

## 继续处理已有任务

点开任意历史任务，直接在输入框继续说话即可。它会接着原有上下文处理，不会重置。

这也是为什么「改需求」比「重开任务」更划算：重开意味着重新描述背景、重新上传文件、重新等一遍规划。

## 并行与切换

- 同时跑多个任务时，对话区会持续更新各自状态，切走再回来不丢进度。
- 每个任务独立的工作空间和权限状态，互不干扰。
- 但要注意：**完全访问权限是全局开关**，开了之后所有任务都生效，包括后建的。

## 什么时候该新开任务

判断标准很简单：**上下文是否还共用**。

| 情况 | 做法 |
| --- | --- |
| 同一份文件继续改 | 原任务里追加 |
| 换了目标，但还用同一批资料 | 可以新开，先 `@` 引用同一批文件 |
| 完全不同的事 | 新开任务、新工作空间 |
| 任务已经很长、开始跑偏 | 新开任务，把结论整理成一段说明带过去 |

第三种情况的收益最明显：干净的工作空间 + 干净的上下文，出错概率低得多。

## 分享与归档

- **分享任务**：对话区顶部「分享任务」会生成公开链接。分享前确认对话里没有敏感文件内容。
- **重命名**：任务标题可改，建议改成「客户名 + 交付物」这种一眼能认的形式。
- **删除**：删除只移除会话记录，磁盘上的产物文件不会被删。
