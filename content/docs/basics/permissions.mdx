WorkBuddy 能读写文件、跑命令、装软件。为了让你敢用，它有两层设计：**权限模式**决定整体访问范围，**安全中心**做细粒度规则。

## 两种权限模式

切换到输入框底部的权限按钮，通过「允许完全访问」开关切换。

| 对比项 | 默认权限 | 完全访问权限 |
| --- | --- | --- |
| 文件访问范围 | 沙箱约束内，越界需授权 | 整台电脑任意位置 |
| 删除/修改文件 | 逐次确认 | 多数直接执行 |
| 终端命令 | 系统级命令需确认 | 可直接运行、装软件、改系统设置 |
| 网络访问 | 受控，敏感动作需确认 | 可访问网站、发送数据 |
| 打断频率 | 较高 | 很低 |
| 生效范围 | 当前任务 | **当前客户端全部任务** |
| 风险 | 低 | 高 |

<Callout type="warn" title="完全访问是全局开关">
开启后，当前客户端内**所有已存在任务和后续新建任务**统一生效；关掉才恢复默认确认流程。它不跨设备，每台机器独立管理。
</Callout>

## 默认权限到底保护什么

### 工作空间边界

工作空间 = 本次任务主要读写的文件夹。空间内的常规文件操作通常直接执行；**超出空间**或命中高风险规则时暂停确认。

这也解释了为什么第一步要选工作空间：给了边界，才有「什么算正常操作」的判断依据。

### 四类需要确认的操作

| 类型 | 举例 |
| --- | --- |
| 写入受保护/敏感路径 | 避免覆盖密钥、凭据、安全配置 |
| 删除受保护文件、重要目录、批量删除 | 避免误删难以恢复的资料 |
| 执行脚本、命令、外部程序 | 可能改文件、访问网络、影响系统 |
| 网络访问或敏感能力 | 命中安全中心规则时 |

取消确认后它不会执行。你可以接着让它换个更安全的方式：先列清单、先生成预览、先备份、把输出存到工作空间内。

### 三层兜底

- **沙箱**：命令优先在约束下执行，被拦截后再按风险决定是否问你。
- **删除保护**：优先走废纸篓/回收站，而不是直接抹掉。
- **自动备份**：修改已有文件前存快照，新建文件不重复备份。可在**设置 → 安全中心**开关。

### 确认弹窗怎么看

弹窗标题说明拦截原因（读取文件 / 写入文件 / 删除文件 / 访问网络 / 执行命令），下方显示操作对象，过长会省略，点击可看完整路径。右上角「查看拦截规则」能跳到对应设置项。

收到弹窗，按三步判断：

1. **操作内容**：写、删，还是跑脚本？
2. **影响范围**：路径在本次工作空间内吗？会不会动到桌面、下载目录、项目源码？
3. **必要性**：这一步真的是完成任务所必需的吗？

拿不准就先取消。

## 什么时候才开完全访问

只在**可信任务 + 隔离环境 + 结果可恢复**三个条件同时成立时短时间开启。典型场景：在 Docker、虚拟机、一次性测试目录里反复跑同一个脚本。

<Callout type="danger" title="这些情况不要开">
- 处理生产资料、客户资料、财务资料或唯一副本
- 工作目录靠近桌面、下载目录、个人文档根目录、项目仓库根目录
- 任务会批量删除、批量重命名、覆盖文件
- 需要运行你不了解的脚本或第三方工具
- 电脑里有重要文件且没有备份
</Callout>

## 工作区信任

首次打开含开发配置目录（如 `.codebuddy`）的工作区时，会弹信任确认：

- **正常打开**：加入信任白名单，后续不再重复询问。
- **受限模式**：仍可浏览、搜索、编辑文件，但不会扫描或运行工作区配置目录下的文件，也不自动加载其中的设置、规则、命令、脚本和插件能力。

信任以工作区目录为单位，各工作区独立判断。看到界面持续显示「受限模式」就说明当前处于限制态。

## 安全中心：更细的旋钮

**设置 → 安全中心**，按组管理：

| 分组 | 内容 |
| --- | --- |
| 沙箱安全 | 总开关；文件安全（三态规则：允许/询问/拒绝）、命令安全（按前缀）、网络安全（按域名）、自动备份 |
| 工具管控 | 逐个启停产品工具与 MCP 服务，对当前客户端所有 Agent 生效 |
| AI 安全防护 | 模型行为智能审查、工具内容注入防护、AI 智能审批（默认全关） |
| 数据安全 | 安全网关、传输加密、敏感保护、删除保护、批量删除审批 |
| 内置运行时 | 允许使用随包提供的运行时工具 |
| 审计中心 | 记录拦截/放行日志，可导出、可清空 |
| 系统授权 | 仅 macOS：完全磁盘访问、辅助功能、自动化 |

### 网络安全

- 远程 HTTP 请求**默认询问**，本地 HTTP 请求**默认放行**。
- 域名白名单内的访问不受网络访问规则限制。
- macOS 可开**网络严格模式**，用系统机制拦住绕过代理的出站连接。SSH、直连数据库这类工具会受影响，用完记得关。

### 敏感保护

默认开启。命中时（如检测到 API Key、Client Secret）弹窗问你：**允许访问 / 允许加密访问（推荐）/ 禁止访问**。选加密访问后，明文存在「敏感数据管理」里，后续对话以密文流转，输出时自动还原。

### 自动备份

默认开启，建议保持。同一个文件在一轮对话内只在首次修改前存快照，可以在**安全中心**点「打开备份目录」查看。所有会话共享备份空间，默认上限 3000 MB，超出按时间清理最早的。

## 一套实用习惯

<Steps>
  <Step title="一个任务一个目录">
    只把需要处理的副本放进去，不动原始资料。
  </Step>
  <Step title="重要文件先备份">
    默认权限能降低风险，但不能代替备份。
  </Step>
  <Step title="默认权限打底">
    让它在该确认的地方停下来问你。
  </Step>
  <Step title="弹窗看路径">
    重点看操作类型和影响范围，别养成闭眼点确认的习惯。
  </Step>
  <Step title="完全访问用完即关">
    临时开，任务结束立刻恢复默认。
  </Step>
</Steps>

## 常见疑问

**默认权限会不会让它什么都做不了？**
不会。沙箱内的常规写入照常执行，只有越界和高危类型才确认。

**完全访问只对当前任务生效吗？**
不是，是客户端级全局开关。

**每一步都会问我吗？**
不是。日常写文档、做表格、生成 PPT 基本不会被拦。
