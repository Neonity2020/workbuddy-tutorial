结果区在右侧，分**概览**和**产物**两个页签。它存在的意义是：你不需要离开当前任务，就能验收、对比、下载。

## 概览

打开右侧面板默认看到概览：

- 本次任务做了什么（摘要）
- 关键结论
- 本次生成的主要产物清单

适合快速回答「这活儿到底干完没有」。

## 产物

产物页签是主战场，里面有三类内容：

<Tabs items={['产物', '全部文件', '文件变更']}>
  <Tab value="产物">
    WorkBuddy 主动交付的成品。卡片上显示文件名、类型、大小，点击可直接在右侧预览：文档翻页、表格查看、PPT 放映、网页在**内置浏览器**里渲染。

    预览面板底部提供下载、在文件夹中显示、用默认应用打开。
  </Tab>
  <Tab value="全部文件">
    当前工作空间里的所有文件，包括你放进去的原始材料。这里相当于一个轻量文件浏览器，可以确认 WorkBuddy 到底读到了什么、写了什么。
  </Tab>
  <Tab value="文件变更">
    本次对话期间被修改的文件及差异。**这是最值得养成习惯看的一栏**——它告诉你哪些原有文件被动了，改了什么。
  </Tab>
</Tabs>

## 版本对比

同一份文件被改过多次时，产物里会保留多个版本。可以：

- 切换到任意历史版本查看；
- 对比两版差异，确认改动范围；
- 把旧版本另存，作为备份。

配合**回退**功能（把对话和产物一起退回某个时间点），基本可以做到「随便试，不怕毁」。

## 内置浏览器

网页类产物在右侧用内置浏览器打开，可以直接点、可以滚动、可以填表单。发现问题当场在对话区说「第二个卡片标题换行错了」，比截图描述快得多。

## 交付给别人的三种方式

| 场景 | 方式 |
| --- | --- |
| 发文件 | 在产物卡片上直接下载，或用「在文件夹中显示」找到原文件 |
| 发过程 | 对话区顶部**分享任务**，生成公开链接 |
| 发成品网页 | 用发布能力把网页/应用变成在线链接（见[做网站](/docs/practice/website)） |

<Callout type="warn" title="分享前检查敏感信息">
分享任务链接会包含对话内容。如果对话里出现客户名单、财务数据、密钥，先确认再分享，或者只下载产物文件。
</Callout>

## 一个验收清单

养成固定动作，能躲掉大部分返工：

- [ ] 数字对不对：抽查两三个值，和原始数据对一遍
- [ ] 口径对不对：金额是含税还是不含税，日期是自然月还是滚动 30 天
- [ ] 格式对不对：字号、页边距、图表配色是否满足交付要求
- [ ] 范围对不对：看「文件变更」，确认没有误改其他文件
- [ ] 能不能打开：Office 文件用目标版本打开一次，别只信预览
